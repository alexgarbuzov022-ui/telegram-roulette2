📥 Библиотека файлов — загрузи один раз

Загрузи файлы в отдельные категории. Затем у каждого приза выбери категорию — при выигрыше бот случайно отправит один файл из неё.

Для больших видео: отправь видео самому боту в Telegram как администратор, скопируй полученный file_id и вставь его в поле «Содержимое приза» с типом «Видео». Так не нужно загружать ролик на сервер. Загрузка с компьютера ограничена 20 МБ на файл.
