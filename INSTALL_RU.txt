ИНСТРУКЦИЯ УСТАНОВКИ ОБНОВЛЕНИЯ

В архиве находятся два файла для замены и этот файл-инструкция.

1. Распакуй ZIP на компьютере.
2. Открой GitHub: https://github.com/alexgarbuzov022-ui/telegram-roulette2
3. Замени файл main.py содержимым из roulette_upgrade/main.py:
   - открой main.py в GitHub;
   - нажми карандаш Edit;
   - замени весь код;
   - нажми Commit changes.
4. Замени web/index.html содержимым из roulette_upgrade/web/index.html:
   - открой папку web в репозитории;
   - открой index.html, нажми Edit;
   - замени весь код;
   - нажми Commit changes.
5. В Render открой сервис telegram-roulette2 и дождись Deploy succeeded / Live.
6. Открой бота в Telegram и отправь /start. Затем открой Mini App.

Переменные Render должны быть сохранены:
BOT_TOKEN = токен бота (не отправляй его в чат)
WEBAPP_URL = https://telegram-roulette2.onrender.com
ADMIN_IDS = числовые Telegram ID через запятую, например 111111111,222222222
SPIN_PRICE_STARS = 50

requirements.txt из этого архива не нужен: в проекте уже используются aiogram, fastapi, uvicorn, python-multipart и python-dotenv. Если в текущем requirements.txt их нет, добавь все пять.

ЧТО ЕСТЬ В ЭТОЙ ВЕРСИИ
- горизонтальная анимированная рулетка;
- фиолетовый неоновый дизайн и нижние вкладки;
- магазин вращений внутри Mini App с оплатой Telegram Stars;
- бесплатные вращения для администраторов из ADMIN_IDS;
- профиль и история;
- раздел «Мои призы» в боте и кнопка получения приза;
- добавление, редактирование и удаление призов в админке;
- выдача текстового кода/текста, ссылки, фото или видео при корректно настроенном типе и содержимом.

ВАЖНО
- Сначала проверь тестовую покупку и тестовый приз.
- Удаление приза необратимо для каталога; проверь на тестовом призе.
- Бесплатный Render может засыпать после простоя.
- SQLite на бесплатном Render может потерять данные при пересоздании экземпляра. Не используй это как надёжное production-хранилище платежей/инвентаря без постоянного диска или внешней базы.
- TelegramConflictError означает, что второй процесс использует тот же токен для polling. Убедись, что не запущена другая копия бота (например, локально или в другом Render-сервисе).
- Цифровые товары внутри Telegram оплачиваются Telegram Stars; не добавляй обходные карточные/крипто-платежи в Mini App.


МЕДИАФАЙЛЫ ДЛЯ ПРИЗОВ
В админке в поле «Фото и видео, которые получит победитель» выберите сразу несколько файлов с телефона/компьютера. Поддерживаются JPG, PNG, WEBP, GIF, MP4, WEBM и MOV; до 20 файлов, каждый до 20 МБ. Фото отправляются альбомами по 10, видео — отдельными сообщениями. При редактировании приза новый выбор файлов заменяет старый список. Файлы хранятся в папке uploads на Render; на бесплатном диске Render файлы могут исчезнуть при пересоздании сервиса, поэтому для постоянного хранения нужен постоянный диск или внешнее хранилище.
